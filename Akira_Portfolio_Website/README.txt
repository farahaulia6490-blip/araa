AKIRA / ARAA PORTFOLIO WEBSITE

CARA UPLOAD KE NETLIFY
1. Ekstrak ZIP ini.
2. Buka https://app.netlify.com/drop
3. Seret folder Akira_Portfolio_Website hasil ekstrak ke area upload.
4. Setelah deploy berhasil, Netlify akan memberi link website yang bisa dibuka dari HP/laptop lain.

FILE UTAMA
- index.html: halaman website
- assets/my-char.jpg: gambar karakter di banner
- assets/artwork-1.jpg dan artwork-2.jpg: gambar sementara untuk bagian Artwork

GANTI GAMBAR ARTWORK
Ganti file artwork-1.jpg dan artwork-2.jpg dengan gambar artwork milikmu. Gunakan nama file yang sama supaya link gambar tetap berfungsi.

CATATAN
Tombol "Hubungi" mengarah ke bagian kontak di halaman. Jika ingin langsung membuka WhatsApp/Instagram, ubah tautannya di index.html.
